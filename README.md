# GovAtende — Serviço de Inteligência Artificial

Serviço em Python responsável pelas funcionalidades de inteligência artificial do GovAtende.

## Funcionalidades

- Classificação automática de solicitações urbanas
- Sugestão de categoria e subserviço
- Análise de urgência e impacto
- Cálculo de prioridade
- Previsão de demandas por bairro e serviço
- Identificação de tendências crescentes, estáveis e decrescentes

## Tecnologias

- Python
- FastAPI
- Pandas
- Uvicorn

## Pré-requisitos

- Python 3.11 ou superior
- pip
